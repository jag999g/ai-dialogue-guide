# Путеводитель по диалогу с ИИ

Сайт для тех, кто хочет научиться общаться с искусственным
интеллектом — без технических терминов, «секретных формул» и страха
что-то сломать.

## Что внутри

- **База (Б-1…Б-7)** — семь коротких уроков: от первого живого диалога до безопасности и проверки фактов.
- **Сценарии (12)** — живые примеры диалогов из разных профессий: строители, преподаватели, художники, исследователи, юристы, врачи и другие.
- **Агенты и локальный запуск** — продвинутый раздел: чем агенты отличаются от обычного чата и как работать локально (и когда этого делать не нужно).
- **Словарь и опоры** — шпаргалки и глоссарий простыми словами.

## Как запустить локально

Сайт — один статический HTML-файл. Просто откройте `index.html` в браузере
(интернет нужен только для CDN: Tailwind CSS, Google Fonts, FontAwesome).

Для локального сервера:

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация

Репозиторий настроен под GitHub Pages: ветка `main`, корень репозитория.
После пуша сайт доступен по адресу
`https://<ваш-логин>.github.io/<имя-репозитория>/`.
